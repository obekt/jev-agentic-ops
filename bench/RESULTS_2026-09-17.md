# A/B results — 2026-09-17 (4 rounds, identical each round)

6 tasks w/ ground truth, Qwen3.8-27b (temp 0) vs jev-latest:
- cost ratio LLM/Jev: 23.2x
- latency ratio: 1.6-1.7x per question (LLM 2.2-2.7s vs Jev ~0.9s)
- mean abs calibration error: LLM 0.030, Jev 0.105  <- LLM wins raw calibration
- action-level (gate 0.5): both 6/6 — tie
- 4-question batch: Jev one call 0.7-0.8s vs LLM 4 sequential calls ~8-11s
- fleet spend logged: 61 calls, $0.0013 total

Conclusion: Jev wins on cost/latency/batch; tie on actions; LLM better on
raw calibration but calibration only matters where actions are sensitive
to probability, which was not the case in any task here. Production policy:
mid-band (0.35-0.65) escalates to reasoning LLM; act-now bar raised to 0.6.
